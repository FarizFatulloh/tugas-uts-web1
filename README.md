## Deskripsi Proyek
Aplikasi Toko Buku Online berbasis frontend (HTML, CSS, dan JavaScript murni) yang terintegrasi secara real-time menggunakan `localStorage`. Fitur meliputi Login, Dashboard interaktif, Katalog Stok dengan pengurangan otomatis, Form Checkout, History Transaksi, Laporan Pemesanan, serta Tracking Pengiriman lengkap dengan lini masa (timeline).
